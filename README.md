# Rezka — Telegram Mini App для домашнего медиасервера

Поиск фильмов и сериалов на HDRezka и загрузка прямо в общую папку сервера (её видно по SMB с телевизора и компьютера). Бот открывает мини-приложение и присылает сообщение, когда загрузка закончилась.

## Как устроено

```
Telegram ─► bot (python-telegram-bot)       кнопка меню + /start, без логики
        └─► Mini App (Svelte 5) ─► backend (FastAPI, aiohttp) ─► HDRezka (поиск, страницы, ajax)
                                         │                     └► CDN (видео, постеры)
                                         ├─ /storage/files/Media   готовые файлы
                                         └─ ./data                 очередь, cookies, метаданные
```

**backend/app**

| модуль | что делает |
|---|---|
| `rezka/client.py` | асинхронный клиент HDRezka: один keep-alive сеанс, таймауты, ретраи, автоматический перелогин, кэш страниц и поиска, cookies сохраняются в `data/` |
| `rezka/parse.py` | чистые парсеры страниц/ajax (покрыты тестами на реальной разметке из `tests/fixtures`) |
| `download/manager.py` | очередь: параллельность, пауза/продолжение/отмена/повтор, сохранение в `data/jobs.json` и автопродолжение после рестарта |
| `download/engine.py` | скачивание: выбор качества по реальному размеру файла, докачка через `Range`, смена зеркал, обновление протухших ссылок, субтитры `.vtt` рядом с видео |
| `streams.py` | разрешение потоков для превью и выбора качества (кэш 15 мин) |
| `library/service.py` | медиатека, место на диске, фоновое сопоставление старых файлов с HDRezka (постеры) |
| `notify.py` | сообщение в Telegram по завершении загрузки |

Раскладка файлов: фильмы — `Название (Год).mp4`, сериалы — `Название (Год)/Сезон N/S01E02.mp4` (папки без года из прошлой версии продолжают использоваться). Во время загрузки рядом лежат `*.part` и `*.part.json` — последний фиксирует, какому качеству принадлежит недокачанный кусок, чтобы докачка никогда не склеила два разных файла.

## Переменные окружения (`.env`)

| переменная | обязательна | описание |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | да | токен бота (им же подписывается авторизация мини-приложения) |
| `ALLOWED_TELEGRAM_IDS` | да | id пользователей через запятую; пусто = доступ всем |
| `HDREZKA_EMAIL`, `HDREZKA_PASSWORD` | да | аккаунт HDRezka (без него сайт показывает стену входа) |
| `HDREZKA_ORIGIN` | | зеркало, по умолчанию `https://rezka.fi` |
| `MINI_APP_URL` | | публичный адрес приложения (кнопка бота и ссылки в уведомлениях) |
| `MEDIA_DIR` | | папка медиатеки, по умолчанию `/storage/files/Media` |
| `SAMBA_UID`, `SAMBA_GID` | | владелец создаваемых файлов, по умолчанию `1000:1000` |
| `DOWNLOAD_CONCURRENCY` | | сколько загрузок идёт одновременно, по умолчанию 2 |
| `NOTIFY_ON_FINISH` | | `false` — не присылать сообщения о завершении |
| `APP_VERSION` | | меняйте при релизе: бот откроет новый URL, и WebView не возьмёт старый кэш |
| `HEARTBEAT_URL`, `HEARTBEAT_TOKEN`, `HEARTBEAT_ID` | | пинги в монитор доступности |
| `DEV_FAKE_USER_ID` | | **только для локальной отладки**: запросы без Telegram считаются этим пользователем |

## Разработка

```bash
cd backend && python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q          # 70+ тестов: парсеры, движок против тестового CDN, API

cd frontend && npm ci
npm run check                          # svelte-check
npm run dev                            # :5173, проксирует /api на :9970
```

Для отладки интерфейса в обычном браузере запустите бэкенд с `DEV_FAKE_USER_ID=1`.

## Деплой

На сервере проект лежит в `/root/HdRezkaDownloaderTG`, запускается через Docker Compose:

```bash
docker compose build && docker compose up -d
docker compose ps                      # backend должен быть (healthy)
```

Остановка/рестарт безопасны: незавершённые загрузки сохраняются и продолжаются после старта (`stop_grace_period: 30s`).

Откат на предыдущий образ: перед обновлением образы помечаются тегом `:rollback`; вернуть их — `docker tag rezka-backend:rollback rezka-backend:latest && docker tag rezka-bot:rollback rezka-bot:latest && docker compose up -d --no-build`.
